# Sitio web de semaforos inteligentes.
Un sitio web sobre semaforos inteligentes en la ciudad de Bilbao. Idea Inovadora para la presentacion del examen practico de confecion de paginas web con html y css.

## funcionalidades de JavaScript agregada para el segundo examen:
- para simular un login con datos hardcodeados.
- mostrar fecha con el dia de la semana en la barra de navegacion.
- deshabilitar boton de envio en el formulario de contacto hasta no seleccionar la casilla de politicas de seguridad
- cambio de imagen en el index en el header hero al entrar y salir el mouse.
